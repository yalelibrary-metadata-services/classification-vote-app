Export Information
Output XML Format:
<records>
  <record bib="12345">
    <title>Title</title>
    <note type="w"
          consensus_probability="0.85"
          vote_count="12">
      Note text...
    </note>
  </record>
</records>
Use Cases:
  • Model Training: Export high-confidence notes (≥80%) for training ML models
  • Quality Review: Export low-confidence notes (50-70%) for manual review
  • Type-Specific: Export only AW or AOW notes for administrative analysis
  • Backup: Export all classified data (0%) for archival
Filters:
  • Confidence: Minimum consensus probability (0-100%)
  • Min Votes: Minimum number of votes required
  • Consensus Type: Include only specific classifications (O, W, OW, AO, AW, AOW, ?)
  • All filters are AND conditions
Notes:
  • Leave consensus types unchecked to export all types
  • Filename includes consensus filter and timestamp
  • Original database is not modified
  • Export can be re-run anytime
